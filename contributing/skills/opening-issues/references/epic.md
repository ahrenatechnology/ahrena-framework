# Epic

Register a new epic for the project

Native issue type: `Epic`. Title: `{{ brief epic summary }}`.

Thank you for contributing with an epic! Please fill out the fields below clearly and objectively.

## Sections, in order

Write each as a `### <label>` heading, as GitHub does when the form is filled in.

### Why is this important?

What is the impact of this epic?

Starts as:

```markdown
Why is this important?
```

For example:

> ex. This epic is important because it will help us to track the progress of the stories within it.

Required.

### What is this about?

Describe the epic in detail

Starts as:

```markdown
What is this about?
```

For example:

> ex. This epic is about the user stories within it.

Optional.

### Acceptance criteria

The epic's outcome, judged by a person, and its sub-issues closed.

Starts as:

```markdown
- AC-1: <the outcome, as the epic's owner would check it> (checked by review)
- AC-2: Every sub-issue is closed. (checked by review)
```

Required.

### Left to other issues

Decisions already made, work blocked elsewhere, and parts another issue owns, each by number.

Optional.
