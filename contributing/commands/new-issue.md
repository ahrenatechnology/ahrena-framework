# /new-issue

Invoke `opening-issues` with the arguments below.

## Arguments

| Argument | Required | Meaning |
|---|---|---|
| what the issue is about | no | The problem or outcome in a few words. Used first to search for an existing issue, then as the starting point for the title |

## What runs

`skills/opening-issues`, from step 1.
